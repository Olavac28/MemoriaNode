É um arquivo usado para enviar requisições HTTP e testar as rotas da sua API.
Precisa da extenção REST Client.

Olhe como funciona:

Send Request                        //botão de teste
POST http://localhost:3333/palavras //rota
Content-Type: application/json      //define como sendo tipo json

//json enviado e que vai cair no parametro request da rota
{
    "palavra": "javascript"
}

### //separa as rotas

//                                parametro; fornece um critério/opção; pode ser feito com outros nomes tbm, de preferencia que descreva o que o parâmetro faz
GET http://localhost:3333/palavras?search=node

###

//                                parametro; identifica um recurso especifico
PUT http://localhost:3333/palavras/1
Content-Type: application/json

{
    "palavra": "c"
}

###

DELETE http://localhost:3333/palavras/1
